## 7. Deliberate non-changes

Recorded because "we could have" is not the same as "we should have":

* **No payment, courier or route adapter was written.** There are no sandbox credentials reachable from this environment, so any code produced would be untestable — and an untested payments path is worse than an honest `503`.
